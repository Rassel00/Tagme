### 설계 결정

- **DB 컬럼은 snake_case, API는 camelCase.** PostgreSQL 관례를 따르고, 변환은 D2의 리포지토리 계층에서 한다. 테이블 `smsJobs` → `sms_jobs`.
- **ORM 없이 SQL 마이그레이션 파일 + `pg`.** 테이블 9개 규모라 ORM 이 주는 이득보다 학습·설정 비용이 큼 (사용자 선택: 최소 구성).
- **ID**
  - 태그 URL 의 tagId(`public_id`)는 base62 24자(약 143비트). 문서 기준 "랜덤 20자 이상" 충족.
  - 신고 ID 는 `al_` + base62 20자 (문서 예시 `al_8x2k...` 형식). 나머지 내부 ID 는 `uuid`.
  - 신고 코드는 6자, 문자로 옮겨 적을 때 헷갈리는 `0 O 1 I L` 제외.
  - 세션·승인 토큰은 32바이트 base64url, DB 에는 SHA-256 해시만 저장. 토큰이 256비트 난수라 솔트·느린 해시가 필요 없음.
- **연락처 최대 3명은 DB 제약으로도 보장**: `sort_order` 0~2 + `(tag_id, sort_order)` 유일.
- **approvals.contact_id 는 `ON DELETE SET NULL`.** 태그 수정(PUT)으로 연락처가 바뀌어도 진행 중 신고의 승인 기록이 지워지지 않게. D2 에서 연락처 수정은 가능한 한 행을 갱신하는 방식으로 구현할 것.
- **테스트는 Node 내장 `node:test` + tsx.** 처음엔 vitest 로 정했으나, vitest 3 에 critical 취약점(tinypool)이 있고 수정판 vitest 5 는 로컬 Node 20.11 과 맞지 않아 뺐다. 패키지 하나 감소.
- **웹은 정적 HTML/CSS + TypeScript(빌드 시 `web/public/js` 로 컴파일).** 프레임워크 없이 화면 3개라 충분. 화면 전환은 해시(`#info`, `#aed`)로 해서 뒤로가기가 자연스럽게 동작.
- **`/t/demo` 는 가짜 API**(`web/src/mock-api.ts`)로 서버·DB 없이 시안 흐름 확인용. 열람 요청 5초 뒤 자동 승인, `?state=notfound|inactive|nocontact` 로 예외 화면 확인.
- **AED 지도는 지도 API 없이 SVG 약식 지도.** 현재 위치와 AED 의 상대 위치만 표시. 길찾기는 카카오맵 링크(`map.kakao.com/link/to`). 지도 API 키·외부 스크립트 의존을 피하려는 것.
- **시안과 다르게 구현한 부분** (개발 문서 1장: 기능은 문서 기준)
  - 시안의 응급정보 화면은 이름·생년월일이 바로 보이지만, 문서 기준으로 공개 항목만 값을 보이고 나머지는 "비공개" 잠금 + 열람 요청 패널.
  - 메인 화면에 비상연락망 알림 결과("보호자 N명에게 발송됨" / "이미 보호자에게 알림이 전송되었습니다") 박스 추가.
- 개발 중 정적 파일 캐시는 끄고, `NODE_ENV=production` 일 때만 1시간 캐시.

### AED API 확인 (WBS 1.7, 11/16)

- 국립중앙의료원 AED 정보 조회 서비스 `getEgytAedManageInfoInqire` 활용 신청 완료(자동 승인), 키로 실제 호출 성공(`resultCode 00`). 키는 `server/.env` 의 `AED_API_KEY` (git 제외).
- 전체 63,651건. `Q0`(시도, 예: `경기도`)·`Q1`(시군구, 예: `수원시` 또는 `수원시 장안구` — 띄어쓰기 필요) 필터 동작 확인: 경기도 13,244 / 수원시 1,007 / 수원시 장안구 214건.
- `numOfRows=5000` 까지 한 번에 받음 (약 5MB, 1.3초) → **전국 적재는 하루 1회 13번 호출**이면 충분. 지역 필터 없이 전국을 받아 두고 거리순 정렬하는 기존 설계(5장) 유지.
- 2.20 적재에 쓸 필드: `serialSeq`(id), `org`(설치기관 → name), `buildPlace`(설치 위치 → place), `buildAddress`(주소), `wgs84Lat`·`wgs84Lon`. 요일별 사용 가능 시간(`monSttTme`…)도 있어 여유 시 표시 가능.
- 주의: 쿼리의 한글은 UTF-8 로 퍼센트 인코딩해야 한다. Git Bash 에서 `curl --data-urlencode` 로 한글을 넘기면 깨져 0건이 나온다 (Node `URLSearchParams` 는 문제없음).

### 설계 결정

- **규칙은 순수 함수**(`src/domain/rules.ts`, `sms-template.ts`)로 분리해 DB 없이 단위 테스트. 라우트는 DB 읽기·쓰기만.
- **병합 규칙 해석** (문서 7.1 이 열어 둔 부분)
  - 재알림은 *같은 버튼*을 다시 눌렀고 마지막 알림 후 5분이 지났을 때만. 다른 버튼을 처음 누를 때는 플래그만 표시.
  - 열람 요청 시 `none`·`expired` → `requested`. `approved` 는 유지(바로 공개), `denied` 는 유지(다른 보호자 승인 대기).
  - 보호자 `approve` 는 거절·만료 후에도 가능(재승인). `deny` 는 `none`·`requested` 일 때만 — 이미 공개 중인 승인을 다른 보호자가 거절로 되돌리지 않음.
- **재알림 때 새 승인 링크를 추가 발급**하고 이전 링크도 유효하게 둔다. 토큰은 해시만 저장하므로 원문을 다시 만들 수 없어서. 결정 상태는 신고 단위라 어느 링크로 처리해도 같다.
- **지도 링크는 `maps.google.com/?q=lat,lng`**. 문자 본문에 한글 없는 ASCII URL 을 쓰려는 것 (카카오맵 링크는 장소명이 URL 에 들어감). 웹의 AED 길찾기는 카카오맵 유지.
- **공개 조회의 잠긴 항목은 값이 있는 항목만.** 빈 항목까지 잠금으로 보여주면 승인 후 "-" 만 나와 혼란스러움.
- **신고 ID·승인 토큰 오류는 존재 여부를 숨긴다.** 쿠키 없음·위조·없는 신고 모두 403 `session_required`, 남의 태그는 404.
- **세션 쿠키 Secure 는 운영(HTTPS)에서만.** localhost·LAN http 테스트에서도 쿠키가 동작하게.
- **24시간 만료는 크론 없이 조회 시점에 판정** (`isAlertOpen`). `closed_at` 은 아직 쓰지 않음.
- **firebase-admin 13** 사용. 14 는 Node 22 이상이 필요한데 로컬이 Node 20. npm audit 에 moderate 1건(`uuid`, Firestore·Storage 하위 의존성)이 남지만 인증 모듈만 쓰므로 영향 없음. Node 22 로 올리면 14 로 교체.
- **통합 테스트는 실제 Postgres 의 임시 스키마**(`test_...`)에 마이그레이션을 적용하고 끝나면 지운다. `TEST_DATABASE_URL`(Neon direct 주소, `search_path` 옵션 때문에 pooler 불가)이 없으면 건너뜀.

### 장난 신고 방지: 같은 IP 의 신규 신고 제한 (11/18)

- **같은 IP 에서 새 신고는 10분 5건, 하루 20건** (`LIMITS.newAlertsPerIpPer10Minutes`, `newAlertsPerIpPerDay`). 넘으면 429 `too_many_alerts` "이 네트워크에서 신고가 너무 많이 접수되었습니다… 위급하면 119에 신고하세요"
- 기존 태그별 제한(1분 1건, 하루 10건)은 한 태그만 막는다. 이번 제한은 한 사람이 여러 태그를 번갈아 신고하는 것을 막는다
- 진행 중인 자기 신고에 다시 누르는 것(병합)은 세지 않는다. 새 신고를 만들 때만 센다
- 수치를 넉넉하게 둔 이유: 이동통신사는 여러 사용자가 IP 하나를 함께 쓴다(CGNAT). 다른 사람의 장난 신고 때문에 실제 응급 신고가 막히면 안 된다
- 메모리 고정 창 방식(기존 공개 조회 제한과 같음). 서버 재시작 시 초기화. Render 에서는 `trust proxy` 로 실제 접속 IP 를 쓴다
- **보호자 쪽 "장난 신고로 표시" 버튼은 만들지 않기로 함**: 실제 응급 상황에서 다른 사람이 신고하는 경우까지 막을 수 있어서
- 테스트 55개 통과 (IP 제한 통합 테스트·기본값 확인 추가)
